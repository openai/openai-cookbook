# AUMARA Interactive Route Storyboard v0.1

## Source clips reviewed

All uploaded clips are vertical 9:16 H.264 at 512×910 and 30 fps. They are suitable as route-reference footage and for a mobile prototype, but the original full-resolution iPhone files should be preserved for production.

## Route map from current material

**IMG_7694.mp4** — 14.1 s

Use: opening movement from the lower path toward the houses and steps.

Interactive role:

- entry to AUMARA;
- “Walk up” transition;

Production note: strong sun flare creates atmosphere but loses detail. Reshoot once at dawn and once at blue hour from the same start/end marks.

### Node 1 — First reveal of the houses

**IMG_7695.mp4** — 8.9 s

Use: first lateral reveal of the yellow, green and red spheres.

Interactive role:

- first branching choice.

- Continue uphill
- Turn toward Chalet
- View site map

### Node 2 — Main approach

**IMG_7696.mp4** — 11.9 s

Use: central forward movement with houses on both sides and red sphere ahead.

Interactive role:

- ideal transition between arrival and central hub.

### Node 3 — Central hub / orientation

**IMG_7697.mp4** — 23.2 s

## What can be built immediately

A mobile-first branching-video prototype:

1. User enters through IMG_7694.
2. IMG_7695 reveals the site.
3. IMG_7696 leads to the central hub.
4. IMG_7697 and IMG_7698 become navigation nodes.
5. IMG_7699, IMG_7700 and IMG_7701 become branch transitions.
6. Hotspots appear only during the final 2–3 seconds of each clip.
7. The next selected clip preloads before the current clip ends.
8. A persistent menu gives access to Stay, Retreats, Private Gatherings, Philosophy and Booking.

This is not free-roaming 3D, but on mobile it can feel like walking through AUMARA and can be shipped much faster.

## Missing production clips

### For every exterior route

Record the same path with:

- horizontal 4K / 30 fps for desktop;
- vertical 4K / 30 fps for mobile;
- 1× main lens;
- exposure and focus locked;
- 2 seconds static at start;
- 6–10 seconds slow movement;
- 3 seconds static at end;
- two identical takes;
- no fast pan during walking.

Mark each camera start and stop point physically with a small removable marker so dawn, day, sunset and night versions align.

### Interior entry sequence for each house type

1. Stable exterior door node.
2. Slow approach to the door.
3. Hand opens door.
4. Continuous entry into the interior.
5. Stable interior hub with clickable zones.
6. Bedroom, bathroom, kitchen/living area and window/view nodes.
7. Exit route back to the same exterior node.

### Time-of-day variants

Repeat the principal route nodes at:

- dawn;
- full daylight;
- sunset / blue hour;
- night with house lighting.

For the prototype, colour treatment can simulate atmosphere. The production release should use real repeated captures from the same marked positions.

### Sound

The camera audio is useful only as scratch sync/reference. Record separate authentic ambience:

- 60 seconds dawn birds;
- 60 seconds daytime wind/trees;
- 60 seconds sunset atmosphere;
- 60 seconds night insects/quiet.

Sound remains off by default and activates only through a visible control.

## Drone role

Drone footage is not required for navigation. It should provide only:

- opening reveal;
- overhead orientation/map image;
- slow pull-away ending;
- one low diagonal pass showing the campus in the landscape.

The ground-level route remains the core interactive experience.

## Recommended production architecture

### Phase 1 — branching film

- current clips as route skeleton;
- clickable hotspots;
- preloaded transitions;
- day/night visual controls;
- booking and enquiry calls to action.

### Phase 2 — 360 interior and exterior hubs

- 360 camera at stable nodes;
- hotspots between nodes;
- house entry and interior exploration.

### Phase 3 — photogrammetry / Gaussian-splat layer

- optional free-view property model;
- used only if mobile performance and conversion remain strong.

## Editorial rule

The interactive layer must never hide the commercial path. At every navigation node the user can:

- book a stay;
- enquire about a retreat;
- request a private gathering;
- return to the site map.
