# Ultrafast examples

These examples demonstrate applications built with the OpenAI API's `ultrafast` service tier. See the [Ultrafast guide](https://developers.openai.com/api/docs/guides/ultrafast-mode) for supported models and availability.

| Example | What you can try |
| --- | --- |
| [Little Worlds](little-worlds/README.md) | Build interactive personal pages with a local Responses agent and compare independent Ultrafast and Standard builds |

Each example documents its own dependencies, API usage, setup, and verification steps.
