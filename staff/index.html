Постоянный адрес AUMARA

Сохраняйте elcidspain.com/staff/. Оболочка AUMARA Staff размещена на нашем Nominalia hosting и обновляется из GitHub без смены ссылки и иконки.

Открыть рабочую AUMARA

На iPhone

Откройте elcidspain.com/staff/ в Safari → «Поделиться» → «На экран Домой». Эту иконку потом менять не понадобится.

Оболочка кэшируется офлайн. Рабочие данные команды, финансов, смен и задач пока синхронизируются с текущим Google backend; перенос этих данных в полноценный local-first режим идёт отдельным этапом.

Текущий режим

Nominalia держит постоянную PWA-точку входа. Google Apps Script пока остаётся рабочим backend приложения v2.0.2. Это переходная схема без Vercel в production.
